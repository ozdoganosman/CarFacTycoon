# Languages (i18n)

The game is written in Turkish; the other languages (English, German, Spanish, Hindi, Arabic) are
translations of it. The Turkish text in the code **is** the source and the lookup key.

- `src/i18n/index.ts`: `t()`, `msg()`, `list()`, the language list, plural forms.
- `src/i18n/format.ts`: numbers, money, percentages and dates in the player's language.
- `src/ui/i18n.tsx`: `tx()`, a translated sentence with bold/coloured parts and React values.
- `src/i18n/load.ts`: which language opens (`?lang=`, the player's choice, the device), loading its catalog.
- `src/i18n/locales/<lang>.json`: `{ key: translation }`, the key being a hash of the Turkish text.
- `src/i18n/source.json`: every Turkish text with where it is, written by `node scripts/i18n-extract.mjs`.
- `tests/i18n.test.ts`: catalogs match the code (placeholders, tags, plural forms).
- `?lang=qps` shows every translated text in ⟦ ⟧: anything on screen without them is not translatable yet.

## Making text translatable

Every text a player can see goes through `t()` (plain text) or `tx()` (rich text in JSX).
**The Turkish output must stay exactly what it was**: same words, spaces, punctuation.

### Plain text: `t()`

```ts
import { t } from '../../i18n';            // relative path from the file

t('Kasa')
t('{name}: tasarımı bitir ve geliştirmeyi başlat.', { name: p.name })
t('{n} hafta', { n: weeks })               // a count is called n (a number) → plural forms in other languages
```

- The first argument is always a **plain string literal** (quotes or a backtick string with no `${}`).
  Never `t(\`${a} b\`)`, never `t(a + 'b')`. Values go in `{placeholders}`.
- Placeholder names: short, lower-case, meaningful (`{name}`, `{cash}`, `{year}`, `{weeks}`).
  A count that decides plural forms is `{n}` and gets the **number** (not a formatted string).
  A big formatted number gets another name: `t('{count} araç satıldı', { count: num(units) })`.
- Pass values already formatted: `money(x)`, `num(x)`, `pct(x)`, `formatDate(w)`, `pctOf(x)`, `inYear(y)`.
  These helpers are language-aware (Turkish suffixes only in Turkish).
- Hand-written Turkish suffixes after a placeholder stay in the Turkish template (`'{name}’in fiyatı'`):
  the other languages rewrite the sentence.
- Keep a sentence whole. Do not translate fragments and glue them (`t('Kasa') + ' ' + t('boş')`).
  If the code picks between variants, write each variant as its own full sentence.
  Lists joined with "ve": `list([a, b, c])` → "a, b ve c" / "a, b and c".
- A text shown in several places is written once and reused.

### Rich text in JSX: `tx()`

```tsx
import { tx } from '../i18n';              // src/ui/i18n.tsx

<p>{tx('Kasa <bad>{cash}</bad>. {weeks} hafta içinde artıya geçmezse şirket iflas eder.', { cash: money(c), weeks: r.weeksLeft })}</p>
```

- Tags: `<b> <i> <em> <strong> <small> <u> <br/>` and the game's tones:
  `<good>` = `<b className="tone-good">`, `<bad>` = `<b className="tone-bad">`,
  `<warn>` = `<b className="tone-warn">`, `<muted>` = `<span className="muted">`.
- Parameters may be React elements (a button, an `<Info>`, a link): `{ btn: <Button …/> }` → `{btn}` in the text.
- For another element around words, pass a tag: `tx('… <go>Projeye git</go>', {}, { go: (c, k) => <a key={k} onClick={…}>{c}</a> })`.
- A JSX text with no markup inside is simply `{t('…')}`.
- String props players read (`title`, `aria-label`, `placeholder`, `alt`, `label`, `sub`, button text) use `t()` too.

### One Turkish word, two meanings: `tc()`

When the same Turkish text means different things in two places (the theme "Açık" is *light*,
a defect "Açık" is *open*), give one of them a context: `tc('tema', 'Açık')`. Turkish shows the
text as it is; the other languages translate each meaning separately.

### Tables of texts: `msg()` where written, `t()` where shown

Texts in tables (module constants, `src/data/*`, option lists, names and descriptions) are marked
with `msg()` where they are written, and shown with `t(value)`:

```ts
export const PHASE_LABEL = { design: msg('Tasarım'), development: msg('Geliştirme') };
…
<span>{t(PHASE_LABEL[p.phase])}</span>
```

- `msg()` returns the text unchanged; it only marks it for the translators (scripts/i18n-extract.mjs).
- A Turkish text used as a key or compared in the code (e.g. research areas `'Motor'`, `'Şanzıman'`)
  keeps working: the table value stays Turkish, only its display goes through `t()`.
- `t(variable)` works for any text that is marked with `msg()` (or appears in a `t()` somewhere).

### Where text is made in the simulation (src/core)

Log lines, newspapers, letters, advice, error messages returned by actions (`fail('…')`) and
anything else a player reads is made with `t()` where it is written. It is stored in the save in the
language of the moment; that is fine.

### Numbers and units

Use `money()`, `num()`, `pct()`, `fmtNumber()`, `formatDate()`. Do not build `'%' + x` or
`x.toFixed(1)` for display (a Turkish-only `toFixed` inside a Turkish-only branch is fine).
Units in text are part of the translated text: `t('{v} km/s', { v })`, `t('{v} kg', { v })`.

### Leave as they are

- ids, keys, CSS classes, analytics event names, `console.*`, `recordError`, comments, tests;
- `decide(...)` texts (a developer log) and texts only sent to the developer (playtest payloads);
- names: companies (rivals), people, cities, states, car models, the player's company and cars;
- Turkish grammar helpers themselves (`src/core/turkish.ts`, `inYear`).

## Checking

```sh
npx tsc -b && npx vitest run            # nothing broken, Turkish unchanged
node scripts/i18n-extract.mjs           # all texts found; no ${} inside t()
# the game with ?lang=qps: every text on screen in ⟦ ⟧
```

## Translating

`src/i18n/source.json` lists every text with where it appears. A catalog entry is
`"<key>": "translation"`, or plural forms `"<key>": { "one": "{n} car", "other": "{n} cars" }`
(Arabic: zero, one, two, few, many, other). Keep every `{placeholder}` and every tag; keep names of
companies, people and places; keep the period voice of newspapers (1900–1960) and the plain,
friendly voice of the game's advice.
