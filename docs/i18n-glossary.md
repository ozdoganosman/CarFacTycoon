# Glossary for translators

The game's own words, so every screen, letter and newspaper uses the same term. Spanish is
neutral Latin American ("auto"). Units stay metric as in the game (km/h, kg, L), but `d/d` is rpm
and `bg` is hp. Names of companies, people, cities, states and car models are never translated.
